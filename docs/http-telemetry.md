# 仅供运维的脱敏请求遥测

[INT-86](https://linear.app/intsheep/issue/INT-86) 为平台 API 和独立 TLS 能力网关向 stderr 输出 `http-request.v1` JSON 行。运维可用它查找拒绝、限流、超时或中断的请求；没有新增租户日志读取入口。

## 记录哪些信息

每个进入 HTTP Handler 的请求记录服务端生成的 `request_id`、UTC Unix 纳秒、固定组件、HTTP 方法枚举、已注册路由模板、状态码、结果类别、耗时纳秒和应用层已写入字节数。服务端同时返回 `X-Agentmoor-Request-ID`，忽略客户提供的同名值。未匹配的路由统一为 `unmatched`，未知方法统一为 `other`。

平台凭据通过验证后，记录实际四维 Scope、与事务审计一致的凭据域摘要及请求的角色；`requested_role` 不代表凭据已拥有该权限，因此权限不足的 403 仍能定位授权凭据。验证失败的请求不记录猜测的 Scope 或凭据摘要。凭据摘要标识的是凭据，不是真实人员帐号。

能力网关验证本次能力及用途后，只记录实际 Scope、Run、可选 Turn 和 `input`/`output`/`model` 委托用途。它不记录能力值或能力摘要。网关的无效、过期、错误用途能力没有可信委托归属。

遥测不接受原始 URL、查询、IP、任意错误、请求头、Prompt、文件、Session、Skill 或模型正文。路由中的客户 ID 不进入模板。平台错误响应也使用固定文案，避免带出被包装的存储错误；服务端不再打印原始错误与路径。后台 reconciliation 失败只输出固定文案。

## 流式输出与结果的含义

响应包装保留 `Unwrap`，使 `http.ResponseController` 可以访问真实连接的读写期限。SSE 刷新、原始截止时间、执行中取消和阻塞下载的撤销仍使用原有连接控制。

`response_bytes` 是应用写入响应层返回的字节数，不代表客户已经收到、验证或持久保存的字节数。若响应先返回 200 再中断，记录仍保留 200，同时 `outcome` 为 `aborted`；不会补写错误 JSON 或假装完整 EOF。尚未发送最终响应头就中断时状态为 0。

普通结果按 HTTP 状态归为 `ok`、`redirect`、`denied`、`not_found`、`conflict`、`not_ready`、`limited`、`unsupported`、`bad_request` 或 `service_error`；请求上下文已取消或到期时可标作 `cancelled`/`deadline`。这些是有界类别，不能据此推断数据库、上游或内核的具体故障原因。任意 panic 值不会进入标准 HTTP 错误日志，连接按原来的中断方式结束并记录 `aborted`。

## 与事务审计的边界

这是尽力写入的运维遥测，不参与业务 SQL 事务，不提供恰好一次、不可变保存或持久审计保证。记录失败不会改写业务响应。拒绝请求不会为每次访问向审计数据库插入一行。[关键状态的持久审计](audit.md) 仍由数据库事务负责。

运维负责 stderr 的采集、访问权限、容量、轮换和保留。日志没有自动导出或自动删除策略；阻塞的日志目标也可能增加请求耗时。TLS 握手失败、HTTP 解析失败和尚未进入 Handler 的服务器拒绝不在此记录范围。没有增加租户计费、真实模型用量或物理 GC 事务保证。

## 验收

代码来源与执行日志摘要见 [2026-11-27 证据](evidence/http-telemetry-2026-11-27.json)。真实 TLS 检查覆盖 ResponseController 期限、SSE 首块在结束前送达、部分响应中断后的错误 EOF、原始 panic 文本不输出，以及实际网关的已验证/未验证身份。真实对象存储错误注入验证响应和默认日志都不带敏感错误正文。既有 64 MiB 阻塞下载撤销、模型流取消和原截止时间测试继续执行。
