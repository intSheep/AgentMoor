# 仅供平台运维读取的审计

2026-11-27 用户确定：首版审计仅供平台运维查看。[INT-84](https://linear.app/intsheep/issue/INT-84) 交付持久事务事件与只读运维入口，是 [INT-83](https://linear.app/intsheep/issue/INT-83) 的第一片。平台保存固定格式的状态事件；运维通过本地只读命令访问现有数据库，不新增租户审计 HTTP 路由或租户权限。

## 首片记录的范围

| 事件 | 可信来源 |
| --- | --- |
| Task/Turn 创建、领取、取消请求及最终状态 | 实际任务事务中的 Scope、Task、Turn、前后状态和 attempt 域摘要。 |
| 资产版本提交 | 已提交版本的种类、资产 ID 域摘要、版本号和内容摘要。 |
| 沙箱输入、创建围栏、模板、Pod、封存与逻辑状态 | 持久 Run 与前后状态，关联固定 Run ID、Pod UID。 |
| 模型预算预留 | 与预算扣除同一事务的累计次数、重写后输入字节和预留输出额度。不是实际 token 或计费记录。 |

审计与上述业务状态使用同一个持有写者租约的数据库事务。审计写入失败时，业务状态不能单独成功；没有状态变化的重投不会重复追加事件。外部对象上传、物理 GC 删除不属于 SQL 事务，不能从这些记录推断它们也已原子完成。逻辑 `collected` 只代表逻辑墓碑状态。

事件不接受任意 payload、消息、路径或错误正文。平台 HTTP 身份在鉴权后派生为凭据的域 SHA256 与固定路由角色；这识别的是授权凭据，不是真实人员帐号。沙箱输出和模型调用在验证本次能力及用途后记录为 `guest-capability/output` 或 `guest-capability/model`，只通过已有 Run 关联委托，不保存能力值或能力摘要。`component` 另行标明处理组件，不能把模型网关或控制器当作来访者。若内部上下文已有真实的平台 HTTP 身份，则保留该凭据身份；请求正文或自定义头不能提供这个上下文。后台控制器仍使用明确的系统来源。

Task、Turn、Run 和 Pod 由平台状态关联。任意资产 ID 只保留域摘要，不从用户可写的 `turns/...` 文件名反推真实追问归属。

事件不保存 token、能力、模型密钥、Prompt、Session、Skill 或交付正文。每条最多 8 KiB，字段、动作和状态有固定校验；读取还拒绝重复 key、未知字段、异常层级或损坏记录。

## 在服务运行时查询

SQLite 使用已有平台目录：

```sh
agentmoor audit --data /var/lib/agentmoor \
  --tenant example --project reports --runtime report-job --adapter codex \
  --limit 100
```

PostgreSQL 使用与受信平台配置一致的 `AGENTMOOR_POSTGRES_DSN` 环境配置，命令中省略 `--data`。数据库凭据按原运维环境配置，不放进命令参数、聊天或导出结果。

结果是 JSON：`events` 为当前页，`next` 为最后已读的全局游标，`total` 为该四维 Scope 的总记录数。下一页传入 `--after <next>`；默认每页 100 条，范围为 1–1000。游标非负，必须填写完整 Scope。`time_unix_nano` 是 UTC Unix 纳秒。默认读取超时 10 秒，`--timeout` 最多一分钟。

只读连接不获取服务写者租约，因此可以与正在运行的平台并存。SQLite 使用经过编码的文件 URI、`mode=ro` 和 query-only；PostgreSQL 每页使用只读、可重复读事务。一页内的总数和记录来自同一快照，不创建目录、数据库或 schema，也不读取平台签名密钥。跨页时可能有新事件追加，游标仍只向前。

运维访问依赖现有文件系统或数据库权限，不依赖 SaaS token。命令输出可以交给运维自己的保存流程；查询本身不写入该日志。本片不自动删除或轮换审计记录，也不改变资产 GC 的保留策略。

## 旧数据库与明确的边界

升级在原目录新增审计表，不重写原 Task、Session、版本或执行围栏。旧库没有历史审计事件，不能事后补造。

SQLite 的旧相对 `file:` 参数及含 `?` 的未编码路径可能曾指向另一文件。遇到旧位置歧义时现在明确拒绝，不静默创建第二份空库，也不自动搬迁或覆盖旧文件；运维应先保留旧库，再按受信维护流程确认实际位置。新位置使用字面绝对路径和编码 URI，NUL 等截断输入直接拒绝。

HTTP 拒绝与耗时、外部对象的物理 GC、成功任务与每个资产的显式链接事件，以及完整运维审计导出/保留治理属于后续范围。本片不能因此标作整个 P2 的“完整审计”已完成；也没有数据库管理员篡改防护或外部不可变归档的保证。
